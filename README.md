THE WORLD brings Friday 20 November 2026 together on one newspaper front page. The ICJ ruling that Myanmar committed genocide leads the edition, alongside the Shenzhen peace declaration, Anthropic's IPO debut, the Gulf war widening to Riyadh, Europe preparing for Ukraine talks, the NVIDIA California probe, and the release of GTA VI. The headlines and pictures let a viewer who missed the day understand what happened from the image alone.

## Stories on the page

- ICJ, The Hague: the UN court rules that Myanmar committed genocide against the Rohingya.
- Shenzhen Summit 2026: Trump, Xi and Putin sign a peace declaration.
- Anthropic soars in a record NYSE IPO debut, gaining 124.3%.
- The Gulf war widens as a missile hits a tower in Riyadh.
- Europe prepares for Ukraine talks in Berlin.
- NVIDIA faces a California probe.
- GTA VI is out.

## How it runs

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Using Node 22 and its standard library, the program creates the output directory and copies the bundled image there as `entry.png`. The default output directory is `/output`. The image is a JPEG, 1024×1024 pixels and under 1 MiB, stored with the required `.png` filename.
